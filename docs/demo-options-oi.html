三行版：一張表 ＝ 一檔契約的一生

用上方的模擬日期切換，可以看整張表怎麼隨契約推進滾動。9/09 之後為模擬數字。

日曆跟著契約走，不是跟著日曆週走
追蹤中的那一檔＝最近一檔還沒結算的週選。它的掛牌日固定落在第一行的週三、結算日落在第三行的週三， 所以今天會在三行之間移動：9/01 在第三行 → 9/02（W1 結算）整張表跳到 W2、今天變第二行 → 9/08 又回到第三行 → 9/09（W2 結算）跳到 W4，今天回到第一行的週三，一路走到 9/23 結算。 第一行的日／一／二（掛牌前）與第三行的四／五／六（結算後）永遠純灰、不放任何標註。
右上角＝下一檔同型週選，掛牌後才出現
月選不進日曆（它有自己的區塊）。週三表只認 W、週五表只認 F。 點右上小字看下一檔、點格子回到追蹤中那檔，明細上方用分頁分開，兩檔不會互相蓋掉。
上一檔的結算價放在明細分頁
契約結算當天日曆就換下一檔了，舊契約已經不在畫面上，所以明細多一個「上一檔」分頁： 最後結算價 ＋ 它結算前最後一天的支撐壓力擺在一起，直接看得出那一輪有沒有守住（例：202609W1 結算 46,223，結算前支撐 46000 → 收在區間內）。
